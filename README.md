# Luban HandPose v11 - ml5 + p5 connected

这个版本专门解决“HandPose没有圆点”的问题。

## 核心修改

1. 按 ml5 HandPose 常见官方示例方式接入：
   - p5.js `createCapture(VIDEO)`
   - `handPose = ml5.handPose()`
   - `handPose.detectStart(video, gotHands)`

2. 画面圆点由 p5.js 直接绘制：
   - 检测到食指：显示圆点
   - 拇指和食指捏合：显示大圆环和 PINCH

3. 兼容多种 ml5 HandPose 输出格式：
   - `hand.index_finger_tip`
   - `hand.keypoints[8]`
   - `hand.landmarks[8]`

4. 圆点连接 Three.js 模型抓取：
   - 圆点位置转 Raycaster
   - 捏合时选择最近/射线命中的木块
   - 松开后靠近目标点会吸附

## 测试步骤

1. 用 Cursor 打开整个文件夹
2. 点击 Go Live
3. 网页打开后，应该会自动请求摄像头权限
4. 允许摄像头
5. 把手放进右上角视频画面
6. 看主画面是否出现食指圆点
7. 拇指和食指捏合，看圆点是否显示 PINCH

## 如果圆点还不出现

请看 Debug Log 是否显示：

- `p5 createCapture ready`
- `handPose.detectStart(video, gotHands) called`
- `hand detected`

如果只显示 `detectStart called`，但没有 `hand detected`，说明摄像头画面中手没有被 HandPose 识别到。
可以尝试：
- 手离摄像头远一点
- 光线更亮
- 手掌完整进入画面
- 背景简单一些

## v17 修改内容：目标模型、深度与最终结果

### 1. 摄像头方向与深度
- 默认让白色点和右上角摄像头画面保持同方向。
- 如果按真实人物左右来看，会与摄像头角度相反，这是正常的镜像交互方式。
- 手离摄像头越近，系统会根据手部关键点距离判断“更近”，并把抓取中的积木往画面内部移动，也就是 Z 值更深。

### 2. 白色透明目标模型
系统现在支持最终摆好状态的目标参考模型。

推荐命名方式如下：

#### 方案 A：一个完整目标模型
把最终 6 块拼好的整体导出为：

models/luban_target/target_full.glb

这个文件会作为白色透明整体参考显示在框中央。

#### 方案 B：六个目标位置模型
如果你想每块都单独作为目标参考，请命名为：

models/luban_target/target_a.glb
models/luban_target/target_b.glb
models/luban_target/target_c.glb
models/luban_target/target_d.glb
models/luban_target/target_e.glb
models/luban_target/target_f.glb

对应原来的活动模型：

luban_a.glb -> target_a.glb
luban_b.glb -> target_b.glb
luban_c.glb -> target_c.glb
luban_d.glb -> target_d.glb
luban_e.glb -> target_e.glb
luban_f.glb -> target_f.glb

### 3. 正确放置后锁定
- 当活动积木靠近白色透明目标位置时，会自动吸附。
- 吸附后该积木变为 locked 状态。
- locked 后不能再被抓取或移动。
- 6 块全部 locked 后，Debug Log 会显示 `GAME COMPLETE`。

### 4. 当前没有目标模型时
如果你还没放 target_full.glb 或 target_a-f.glb，系统会用当前 6 个模型自动生成一个白色透明的临时目标轮廓。
后续你发来最终摆好状态模型后，直接放入 `models/luban_target/` 文件夹即可。
